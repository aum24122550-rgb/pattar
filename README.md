# patta

เว็บแนะนำสูตรอาหารสำหรับผู้ป่วยโรคไต (ก่อนฟอกไต)

## ความสามารถหลัก
- ค้นหาสูตรอาหารจากชื่อเมนูหรือวัตถุดิบ
- เลือกระยะไต (ระยะ 3, 4, 5 ก่อนฟอกไต) เพื่อกรองสูตรที่เหมาะสมจริงในระยะนั้น
- เพิ่มสูตรอาหารเฉพาะของแต่ละระยะให้มากขึ้น (ระยะละหลายเมนู)
- สูตรเฉพาะระยะจะมี `targetStage` และต้องผ่านเกณฑ์โภชนาการของระยะนั้นจริงก่อนแสดงผล
- ใช้เกณฑ์โภชนาการในการแนะนำสูตร: โซเดียม, โพแทสเซียม, ฟอสฟอรัส และแคลเซียม
- เพิ่มรูปอาหารให้แต่ละเมนูจากลิงก์รูปอาหารบนอินเทอร์เน็ต (แสดงในหน้ารวมสูตรและหน้ารายละเอียด)
- แสดงป้ายในแต่ละเมนูว่าเหมาะกับระยะไตใด พร้อมดูรายละเอียดโภชนาการรายเมนู
- หน้าแอดมินมีระบบล็อกอินก่อนเข้าใช้งาน และเข้าผ่านปุ่ม "แอดมิน" ที่มุมขวาบนของหน้าเว็บหลัก
- หน้ารายละเอียดสูตรโฉมใหม่แบบการ์ดสมัยใหม่ อ่านง่ายทั้งมือถือและเดสก์ท็อป
- คอมเมนต์และให้คะแนนสูตรอาหาร (เก็บใน localStorage)

- แดชบอร์ดแอดมินแสดงสรุป: จำนวนสมาชิก, จำนวนสูตรทั้งหมด, และสูตรยอดนิยม
